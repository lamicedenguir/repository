# Software Portfolio

This section presents the principal software products designed and developed by Dr. Eng. Lamice Denguir. Each project illustrates a different aspect of her software engineering journey, from web platforms and event management systems to cross-platform mobile applications and AI-assisted engineering concepts.

For each project, the repository provides an overview of the problem addressed, key features, software architecture, development approach, demonstrations, technical documentation, and representative implementation examples where appropriate.

## Portfolio Structure

* **01 – KS-Portal (2020)**
  A digital platform developed for the Knowledge & Skills startup to support engineering training, audiovisual scientific publication, and educational activities.

* **02 – KS-Conference (2021)**
  A web application designed to organize and manage scientific conferences, including participant remote attendance, program management, event communication, and conference replay.

* **03 – Tortoise (2025)**
  A youth-destined application exploring intelligent task management and human-centered software design.

* **04 – Growing Journey (2026)**
  A privacy-first cross-platform journaling application that helps parents document, organize, and preserve their child's developmental journey while keeping all personal data stored locally on the user's device.
